# Boneco 3D do jogador (VRoid / VRM)

O jogo **não traz nenhum modelo 3D pronto**. O boneco 3D é opcional e usa só o
modelo que o próprio jogador carregar.

## Como usar

1. Abra *Configurações → Boneco 3D (VRoid)* e ligue a opção.
2. Em *Seu modelo .vrm*, toque em **Carregar arquivo** e escolha um `.vrm`.
3. O modelo fica salvo só no seu aparelho e vale para todas as classes, com o
   visual de cada classe (cor da roupa, elmo, capuz, capa…) por cima.
4. **Remover** apaga o modelo do aparelho e o jogo volta ao boneco normal.

## Como criar um personagem no VRoid Studio

1. Baixe o VRoid Studio (gratuito) e crie o personagem.
2. **Exportar → Exportar como VRM** e escolha **VRM 0.0** (o VRM 1.0 ainda não
   funciona com a versão do motor do jogo).
3. Reduza as texturas para 1024 ou 512 e o número de polígonos, para o jogo
   ficar leve no celular.

Use só modelos que você criou ou que tenham licença que permita esse uso.
